# Checklists

Verify every deadline live on the official FAQ. Put tasks with owners and due dates into `actions` in the state file so they show up in the workbook.

## T-14 days
- Sync the calendar; file what's already booked.
- Reserve must-attend seats in the AWS Events app - workshops, chalk talks and builder sessions first - plus backups and repeat sessions.
- RSVP to side events that are still open.
- Ask the partner development manager or account manager about invite-only events.
- Draft meeting outreach (user sends).
- App installed, Builder ID set up, attendee photo uploaded if required.
- Hotel and flights confirmed; know the nearest shuttle stop.
- Decide the one ask for AWS this week.

## T-7 days
- Confirm meetings and holds.
- Lock 1-2 venues per day.
- Last RSVPs.
- Meeting briefs drafted.
- Dietary and accessibility requests through the official channel if available.
- Certification voucher or exam booking if relevant.

## T-1 day
- Badge pickup plan with ID.
- First shuttle and leave-by for day one.
- Tomorrow's Today view built.
- Pack and charge everything.
- Release reserved seats they won't use (kind to others, and some systems track no-shows).
- Sleep.

## Each day on site
- Morning brief, then tonight's events loop.
- Arrive early to reserved sessions.
- Protect one meal and drink water.
- Same-day follow-ups after meetings.
- Evening recap.

## Week after
- 48-hour follow-ups.
- Pipeline updated with only what the user confirms.
- Queue the official recordings worth watching.
- Start 90-day mode.

## Last-minute (2 weeks or less - run alongside T-14)
- What's still open today: sessions, side events, meeting slots.
- If sessions are full: walk-up lines, hallway, Expo, Ask the Experts, content hubs.
- Meetings first - breakfast, coffee and Expo meetings are the easiest to book late.
- Plan B for full sessions.
- Badge, hotel, shuttle, app, packing, and any official deadlines still ahead.
